# 棒球击球声受控仿真探针研究

**日期：** 2026-08-11
**任务：** contact-audio-simulation（地图：`.scratch/contact-audio-simulation/map.md`）
**结论先行：** 受控合成击球声的物理参数在干净条件下可被冻结 181D 与 M2D 仪器完整测出（四族自检通过）；但在球场广播噪声条件下，**只有"强度"类绝对电平线索幸存**，位置、衰减、锐度等形状/尾巴线索被噪声掩盖——这是一个稳健的负面环境迁移发现，并为 `audio-research-recovery` 主研究提供四条可交接的混淆假设。

---

## 1. 本轮问题

主研究（fly/ground 音频分类）面临的核心困难：真实数据集来自广播视频，标签与采集属性（片段长度、削波、噪声）高度混淆，无法在真实数据上分离"接触物理信息"与"采集环境信息"的机制。

本工作用**受控合成**的方式绕开这一混淆：用论文中的物理参数合成击球声（模态合成），通过模拟环境网格和采集退化处理，测量冻结特征仪器对**已知物理参数**的跟踪能力，从而回答：

1. 冻结仪器（181D 传统特征、M2D 40ms）是否携带击球接触的结构信息？
2. 广播条件下的距离与噪声会摧毁哪些物理线索、幸存哪些？
3. 哪些特征组是"接触载体"、哪些是"环境指纹"（采集条件驱动）？

设计由议题 01（可行性调研）→ 02（原型试听）→ 03（M2D 验证）→ 04（设计锁定）逐级推进，全部决策记录在 `.scratch/contact-audio-simulation/issues/`。

## 2. 方法与数据

### 2.1 合成（模态合成，numpy）

每个基础信号 = 0.1s 处的宽带点击激励（0.2–1.0ms 或锐度族的 0.1–1.6ms）+ 12 个阻尼正弦模态（150Hz–6kHz 对数分布，高频模态衰减更快，±0.5% 失谐）+ 粉红噪声地板。四个**单物理参数族**，每族 5 档，每档 5 个随机变体（种子固定），共 **100 个基础信号**，2.0s @ 16kHz（32000 采样）。

| 参数族 | 档位 | 物理含义 |
|---|---|---|
| 强度 | 0.2→1.0（L^1.5，约 21dB，含频谱倾斜） | 击打力量 |
| 位置 | 0→1（甜点→偏离中心，高模态激发比） | 击球点 |
| 衰减 | 0.5×→2× 阻尼 | 材料/球棒 |
| 锐度 | 0.1–1.6ms 点击，1/τ 高通（迭代 2 修复） | 激励锐度 |

### 2.2 环境网格（8 格，球场广播条件）

参考格（1m、无噪声、无空气吸收）+ 1m@30dB + 10m@{30,15,5}dB + 30m@{30,15,5}dB（≥10m 开空气吸收）。**无房间混响**（经用户确认排除）。噪声为粉红噪声，SNR 相对瞬态峰值定义。

### 2.3 采集退化（中场格 10m@15dB，一次一个）

无 / 硬削波（相对峰值 0.5×、0.25×——迭代 2 修正，绝对阈值在迭代 1 中为空转）/ MP3-128k / AAC-64k / 截断 1.0s / 截断 0.5s。

### 2.4 仪器与指标

- **181D 传统特征**：纯 numpy/scipy，无头运行（全部 1600 文件）
- **M2D 40ms**：vector 环境 CPU 无头运行（锁定子集 900 文件，2304 维 = 768 × mean/std/max）
- **端点分离度**：每族 L1 vs L5（各 5 变体），冻结 logreg（`run_logreg_regularized.py`），StratifiedKFold(5) × 10 次重复，平衡准确率均值
- **参数跟踪**：每特征对 25 样本（5 档 × 5 变体）的 Spearman ρ
- **特征组消融**：181D 七组（logmel 80 / spectral_stats 44 / mfcc 26 / time_domain 11 / frame_energy 8 / band_ratios 8 / local_transient 4），留一去一（LOGO）+ 单组进入（SGI）
- **环境指纹**：每族每格每特征 drift = |mean(c) − mean(参考)| / (sd(参考) + ε)，ε = 1e-6 × 参考格尺度（迭代 2 修正）；按组取均值

### 2.5 预注册成功标准

1. 参考格自检：端点 BA ≥ 0.85 **且**每族至少 1 个特征 |ρ| ≥ 0.9
2. 中场格跟踪：≥ 3/4 族保留 |ρ| ≥ 0.9 单调跟踪
3. 至少 1 条锁定形式的定量环境发现（"条件 X 在严重度 S 下把特征组 F 推离超过 k 个类内标准差 / 端点分离度从 p₁ 打到 p₂"）——坏消息也算成功
4. 消融点名接触载体组与环境驱动组

失败路径（预注册）：自检不过 → 收窄或停；自检过但迁移崩 → 合法负面发现。

## 3. 结果

### 3.1 预注册判定（迭代 2，协议修正后）

| 标准 | 判定 | 结果 |
|---|---|---|
| 1. 参考格自检 | ✅ | BA 四族全 1.00；强特征数：强度 132 / 位置 3 / 衰减 139 / 锐度 19（最佳 ρ −0.969，feat_band_0_1000_ratio） |
| 2. 中场格跟踪 | ❌ | 仅强度（57 个强特征）；位置/衰减/锐度 0 个；端点 BA 1.00 / 0.51 / 0.67 / 0.68 |
| 3. 定量环境发现 | ✅ | 10m/15dB 下位置族 time_domain 组漂移 **322.05 参考标准差**，端点 BA **1.00→0.51** |
| 4. 消融点名 | ✅ | logmel 头号接触载体（SGI BA 0.883，移除使 BA 变化 −0.035）；time_domain 为良态最大环境指纹 |

### 3.2 两轮迭代的故事

- **迭代 1**：锐度族自检失败（无 |ρ|≥0.9 特征，最佳 −0.816）——信息多元可分（BA 1.00）但无单调标量；削波为空转（中场格峰值 ≤0.1597，绝对阈值永不触发）；漂移统计量 3 组无穷大（参考格零方差特征）。
- **迭代 2（协议修复）**：锐度重参数化（1/τ 高通绑定频谱倾斜）→ 自检通过（−0.969，19 个强特征）；削波改相对阈值 → 全部触发；ε 稳定漂移 → 大部分组有限。
- **不变的核心结论**：中场格跟踪始终只有强度族存活（181D 与 M2D 一致）——**转移崩塌是稳健的科学结论，不是协议缺陷**。

### 3.3 关键结果

**181D 端点 BA（中场格）与削波（相对）的交互：**

| 仪器 | 族 | 无退化 | 0.5× 削波 | 0.25× 削波 |
|---|---|---|---|---|
| 181D | 强度 | 1.00 | 1.00 | 0.90 |
| 181D | 位置 | 0.51 | 0.52 | 0.54 |
| 181D | 衰减 | 0.67 | 0.68 | 0.70 |
| 181D | 锐度 | 0.68 | 0.78 | 0.70 |
| M2D | 强度 | 1.00 | 1.00 | 1.00 |
| M2D | 位置 | 0.35 | 0.29 | 0.19 |
| M2D | 衰减 | 0.84 | 0.67 | 0.60 |
| M2D | 锐度 | 0.90 | 0.92 | 0.64 |

**环境指纹（组均值漂移，参考标准差单位）：**

| 特征组 | 均值漂移 | 解读 |
|---|---|---|
| spectral_stats | 无穷大* | 方差地板诊断，非效应量 |
| frame_energy | 6.21×10¹³* | 同上 |
| local_transient | 1.25×10¹³* | 同上 |
| time_domain | 228.44 | **良态最大环境指纹** |
| logmel | 57.20 | 强接触载体 + 显著环境漂移 |

\* 三个参考格恒零特征（spectral_flux_p10 族）在 ε 稳定后仍产生无穷/极大值，作为方差地板诊断交接，不作物理解释。

**M2D 补充**：干净参考格四族全过（锐度 204 个强维度，最佳 ρ −0.981，BA 1.00）；中场格仅强度保留强跟踪（BA 1.00/0.35/0.84/0.90）——黑箱 embedding 不能拯救转移失败，但锐度中场 BA 从迭代 1 的 0.59 升至 0.90。

## 4. 结论

1. **仪器验证**：冻结 181D 与 M2D 在干净条件下完整测出四种已知物理参数（单调跟踪 + 完美端点分离）——测量链确实携带接触结构信息。
2. **负面迁移发现（稳健）**：广播噪声（10m/15dB）下只有**强度**（绝对电平/频谱能量编码）幸存；位置、衰减、锐度依赖的"形状与尾巴"线索被噪声掩盖。181D 与 M2D 双仪器、双轮迭代（含协议修复）结论一致。
3. **削波是采集属性**：相对削波不破坏强度跟踪，但显著改变端点分离（尤其 M2D 位置/衰减/锐度）——真实数据研究应把削波严重度当作采集属性对待。
4. **logmel 双刃剑**：携带最多端点信息，同时大幅随环境漂移——真实数据中依赖 logmel 的分类器可能学到采集条件（距离/噪声）而非接触物理。

## 5. 对主研究的建议（可交接假设）

以下为假设交接，非对 `audio-research-recovery` 地图的决定：

1. **logmel 混淆假设**：真实分类器若以 logmel 类特征为主，需验证其学习的是采集条件还是接触物理。
2. **形状线索需要显式噪声鲁棒**：位置/衰减/锐度类线索在广播噪声下不可靠；若主研究要使用这类线索，需显式噪声鲁棒处理而非更宽的干净合成范围。
3. **削波/截断为采集属性**：退化实验证实截断与削波可实质性改变特征与分离度，主研究的混淆控制应将其作为独立维度。
4. **方差地板诊断**：能量/谱通量统计量在干净参考下零方差，其环境漂移量极大——主研究在 SD 归一化分析中应识别这类"恒零特征"。
