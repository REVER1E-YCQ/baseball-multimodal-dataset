# 标签保持增强评估（2026-08-10）

**状态：** 已完成，方向关闭（无增益）；**数据：** 同锁定基准快照

## 问题

若部署环境与采集环境存在录音条件差异，训练时加入标签保持的录音条件增强（时间抖动、增益、轻度 EQ 及其组合）能否提高 event BA？

## 方法

在锁定协议的训练折内施加四种增强臂（time_jitter / gain / light_eq / combined），3 个折种子重复，与 no_augmentation 对照。

## 结果

| 增强臂 | Event BA（3 种子范围） | 相对对照 |
|---|---|---|
| 无增强（对照） | 0.644–0.667 | — |
| gain | 0.637–0.661 | ≈中性 |
| light_eq | 0.643–0.665 | ≈中性 |
| time_jitter | 0.588–0.638 | **变差** |
| combined | 0.619–0.634 | 变差 |

所有增强下严格 Pre 负控保持随机，结果可信。

## 结论

- 录音条件增强没有稳定收益；**时间抖动一致地伤性能**——与对齐敏感性诊断（中等对齐依赖）相互印证：击球瞬态的精确位置本身携带信息。
- 数据增强方向关闭；提升应从数据质量/数量而非变换入手。
