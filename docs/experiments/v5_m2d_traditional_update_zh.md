# V5 新数据 M2D 与 Traditional 重跑报告

## 1. 本轮问题

远程 `main` 增加到约 2000 条样本后，本轮只回答三个问题：

1. 原来推荐的冻结 M2D baseline 在更多数据上是否仍可区分 fly ball / ground ball；
2. 200 ms 事件窗的效果是否明显高于完全排除击球声的严格 Pre；
3. 在 Codex 自动采集数据上训练的模型能否迁移到人工采集数据。

没有重新微调音频大模型，也没有先跑其他全部预训练模型。

## 2. 固定数据与有效样本

- 仓库：`REVER1E-YCQ/baseball-multimodal-dataset`
- 固定 commit：`5b38414fd257c9ffc54c396af51ee0fb9594b7a2`
- 下载内容：2135 组 `audio.wav + sample.csv + label.txt + source.txt`
- Git blob SHA 校验：8540/8540 文件通过，0 失败
- 视频未下载：本轮是纯音频实验
- 有效样本：2134
- 无效样本：1

无效样本为 `fly_ball/Codex_Workstation/F_1113`。其标注区间是
`[1.950, 2.050]s`，但音频只有约 `2.027s`，因此没有静默截断或补零，
而是保守排除。

| 数据角色 | Fly | Ground | 合计 |
|---|---:|---:|---:|
| Codex 主开发集 | 1172 | 875 | 2047 |
| 人工外部测试 | 34 | 53 | 87 |
| 全部有效数据 | 1206 | 928 | 2134 |

人工外部测试中，34 条 fly 全来自 `Zhengxuan_Liu`，53 条 ground 来自
`Diqing_Tang` 和 `Haoran_Yan`。因此外部测试同时改变了类别和采集者，
可以用于发现迁移失败，但不能单独证明纯粹的击球物理差异。

## 3. 数据审计

### 3.1 来源分组

- 全部有效数据有 2086 个来源组；
- 2081 个是单样本组，只有 5 个多样本组；
- Codex 主开发集的 1851 个 event/Pre 配对样本全部是单样本来源组。

因此主开发集的 `StratifiedGroupKFold` 实际上等价于普通分层交叉验证。
它防止不了同一采集模板造成的偏差，真正的跨流程检查要看人工外部测试。

### 3.2 明显的采集模板偏差

- Fly 完整音频中位长度约 7.019 秒；
- Ground 完整音频中位长度约 6.016 秒；
- 只使用完整音频总长度的 5 折逻辑回归，BA 约 0.934；
- 只使用 `event_start/event_end/区间长度`，BA 约 0.613。

正式音频模型只使用固定 200 ms 窗口，不会直接看到完整音频总长度。
但这些结果证明两类数据来自明显不同的采集或剪辑流程，因此高分不能自动
解释成模型学到了击球声。

### 3.3 严格 Pre 可用性

严格 Pre 定义为：200 ms 窗口结束于 `event_start` 前 50 ms，不补零。

- Codex Fly 可配对：1132/1172；
- Codex Ground 可配对：719/875；
- 主评估最终使用 1851 个 event/Pre 配对 UID；
- 人工外部 87 条全部可配对。

## 4. 方法

### 4.1 窗口

- event：在人工标注 `[event_start, event_end]` 区间内找绝对幅度峰值，
  以峰值为中心截取 200 ms；
- strict Pre：同样 200 ms，但结束于 `event_start - 50ms`；
- 不使用标签寻找峰值；
- 不做 WAV 边界补零；
- 全部窗口长度严格为 200 ms。

### 4.2 特征

- Traditional：181 维时域、频域、频带、log-mel 和 MFCC 统计量；
- M2D：冻结 `m2d_vit_base-80x200p16x4-230529`；
- M2D 使用 CUDA/AMP，只提 embedding，不微调编码器；
- M2D 最后一层时间戳 token 做 mean/std/max，得到 2304 维；
- 编码器训练轮数为 0。

### 4.3 分类器

- `StandardScaler + L2 Logistic Regression`；
- `class_weight=balanced`；
- 无 PCA；
- 5 折外层 OOF，重复 5 次；
- `C` 只在每个外层训练折内部从 `{0.001, 0.01, 0.1}` 选择；
- scaler 和 C 选择都不接触外层测试折；
- M2D 的 25 个 event 外层模型中，23 次选择 `C=0.001`；
- M2D 逻辑回归通常 4 至 5 次 solver iteration 收敛，不是训练大模型的 epoch。

## 5. 主开发集结果

### 5.1 V5

| 特征 | 条件 | BA | ROC-AUC | Macro-F1 | MCC |
|---|---|---:|---:|---:|---:|
| M2D | event 模型→event | 0.606 ± 0.006 | 0.646 ± 0.011 | 0.597 ± 0.005 | 0.206 ± 0.011 |
| M2D | event 模型→Pre | 0.584 ± 0.003 | 0.621 ± 0.010 | 0.534 ± 0.005 | 0.176 ± 0.007 |
| M2D | Pre 模型→Pre | 0.587 ± 0.008 | 0.616 ± 0.005 | 0.577 ± 0.007 | 0.170 ± 0.015 |
| Traditional | event 模型→event | 0.587 ± 0.008 | 0.618 ± 0.008 | 0.576 ± 0.008 | 0.169 ± 0.016 |
| Traditional | event 模型→Pre | 0.582 ± 0.008 | 0.612 ± 0.010 | 0.527 ± 0.006 | 0.177 ± 0.018 |
| Traditional | Pre 模型→Pre | 0.579 ± 0.006 | 0.608 ± 0.010 | 0.567 ± 0.006 | 0.154 ± 0.011 |

### 5.2 与 V4 的同协议比较

| 特征 | 数据 | Event BA | Event→Pre BA | Pre→Pre BA | Event 增量 |
|---|---|---:|---:|---:|---:|
| M2D | V4，n=319 | 0.608 | 0.552 | 0.559 | 0.055 |
| M2D | V5，n=1851 | 0.606 | 0.584 | 0.587 | 0.022 |
| Traditional | V4，n=319 | 0.538 | 0.529 | 0.535 | 0.009 |
| Traditional | V5，n=1851 | 0.587 | 0.582 | 0.579 | 0.005 |

这里的“Event 增量”是 `event 模型→event` 减去同一 event 模型应用到
严格 Pre 的 BA，只用于描述，不是一个独立训练的新模型。

主要变化：

1. M2D 的 event BA 几乎没有变化，仍约 0.61；
2. M2D 的严格 Pre 从约 0.55 升到约 0.58，事件增量从 0.055 降到 0.022；
3. Traditional 的 event 和 Pre 同时明显升高，但两者几乎一样；
4. 新数据减少了随机划分波动，却强化了背景/采集流程中的标签信息；
5. M2D 仍是 Codex 主开发集上较好的 baseline，但不能据此声称主要学到击球瞬态。

## 6. Codex→人工外部测试

训练时只使用 Codex 主开发集，`C=0.001` 在主开发集内部确定；人工数据
不参与 scaler、分类器或 C 的选择。

| 特征 | 条件 | BA | ROC-AUC | Macro-F1 | MCC |
|---|---|---:|---:|---:|---:|
| M2D | event→event | 0.490 | 0.464 | 0.471 | -0.024 |
| M2D | event→Pre | 0.469 | 0.456 | 0.416 | -0.092 |
| Traditional | event→event | 0.675 | 0.874 | 0.679 | 0.376 |
| Traditional | event→Pre | 0.575 | 0.815 | 0.544 | 0.228 |

外部 event 的分层 bootstrap 粗略 95% 区间：

- M2D BA：约 `[0.398, 0.581]`；
- Traditional BA：约 `[0.578, 0.772]`。

M2D 在 Codex 数据中学到的方向没有迁移到人工数据。Traditional 外部结果
明显更好，并出现约 0.10 的 event/Pre BA 差；但由于人工类别与采集者完全
绑定，不能把 0.675 直接解释成无偏的跨人泛化准确率。

## 7. 结论

1. **M2D 仍可作为 Codex 主数据上的推荐 embedding baseline**，因为它在
   统一嵌套评估下优于 Traditional。
2. **更多数据没有增强事件专属证据**。M2D event 分数保持约 0.61，但 Pre
   分数显著升高，event 增量反而缩小。
3. **不能排除上下文和采集模板影响**。完整时长本身几乎可以区分类别，
   Traditional 在 event 与 Pre 上也几乎一样。
4. **M2D 暂未表现出跨采集者泛化**。在人工外部数据上约为随机。
5. 当前更准确的科研表述是：现有 Codex 数据存在稳定的可分信号，M2D 是
   较好的主集 baseline；但信号很大一部分与采集流程或背景有关，尚不能证明
   模型主要依据 fly/ground 的击球物理声音。

## 8. 对代码上传的建议

上传“目前效果最好模型代码”时，建议包含：

- M2D 冻结 embedding + 无 PCA L2 逻辑回归主流程；
- Traditional 181D 对照；
- strict Pre 负控；
- Codex→人工 external holdout 评估；
- 本报告中的限制说明。

不要只上传一个 M2D event 准确率，也不要把 M2D 描述成已经跨采集环境验证的
最终模型。模型权重、音频、embedding CSV 和本机绝对路径仍不应提交。
