# 冻结音频表征区分 Fly Ball 与 Ground Ball 的统一基准

版本：V4；数据截止：2026-07-16；任务：仅使用音频区分 `fly_ball` 与 `ground_ball`。

## 一页结论

本阶段的目标是回答两个不同问题：第一，现有音频里是否存在能让模型区分 fly ball 和 ground ball 的信息；第二，这些信息是否主要来自击球瞬态，而不是录音环境、裁剪方式或事件前后的上下文。第一问得到肯定但强度有限的证据，第二问目前不能得到肯定结论。

- 在统一的 320 条 `primary_dev` 样本上，M2D 是当前最稳健的冻结 embedding。确认性检验使用固定 `C=0.01` 和固定一套来源分组 5 折 OOF：200 ms 观察 BA 为 **0.616**，在 10 个模型中做 max-stat 校正后 `p=0.01`；1000 ms 观察 BA 为 **0.645**，11 模型校正后同样 `p=0.01`。
- 但是，1000 ms 下移除人工标注事件后，ATST 和 M2D 的同一事件分类器仍分别约为 **0.62** 和 **0.62 BA**，几乎没有低于含事件窗口。这说明长窗口高分主要不能归因于击球本身。
- 200 ms 下，M2D 的事件 BA 约 **0.61**，同一事件分类器用于严格 Pre 约 **0.55**。这里存在约 0.06 的事件增量，但严格 Pre 仍高于随机，说明短窗减少了上下文影响，却没有彻底消除采集偏差。
- 原文件总时长本身能 100% 区分类别：fly 约 6.997-7.019 s，ground 约 5.995-6.016 s，范围不重叠。总时长没有输入音频分类器，固定窗口也去除了直接时长信息；但这证明两类采用了不同裁剪流程，背景、编码或录制链仍可能残留类别线索。
- 当前推荐 baseline 是 **冻结 M2D embedding + StandardScaler + L2 逻辑回归（C 只在 0.001/0.01/0.1 内层选择）**。主事件窗口建议先用 200 ms，同时保留 100/50 ms 敏感性分析和严格 Pre 负控。现阶段不建议端到端微调大型编码器。

结论措辞应是：**现有数据在来源分组交叉验证下存在弱到中等的可分信号，M2D 最稳定；但事件移除和元数据审计表明上下文/采集流程影响显著，因此尚不能证明模型主要学到了 fly/ground 的击球物理差异。**

## 1. 从第一性原理看实验要证明什么

一个可靠的证据链需要同时满足：含击球事件的窗口能分类；完全不含击球的负控不能同样分类；同一分类规则移除击球后明显失效；结果在未见来源上成立；并且高分不只是因为同时试了很多模型。只满足第一条，只能证明“文件里有可分信息”，不能证明“击球声有可分信息”。

本报告把实验分成四层：固定条件公平比较、训练折内模型/窗口选择、严格负控、标签置换。冻结编码器意味着预训练模型训练轮数为 0；神经网络只负责把声音转成 embedding，真正用本项目标签训练的是小型分类器。

## 2. 数据、标签与切窗

- 可开发样本：320 条，其中 fly ball 102 条、ground ball 218 条。类别不平衡，因此普通 accuracy 不是主指标。
- `primary_locked_test` 81 条没有用于模型选择；`external_test` 87 条因采集者与标签高度绑定，不用于主排名。
- 原始人工标注给出 `[event_start, event_end]`，新 Codex 数据的 `event_end` 按事件结束理解，不当成峰值。
- 主峰值定位：先用人工标注限定事件范围，再在该范围内寻找原始波形绝对振幅最大的采样点，即 `argmax(|waveform|)`。类别标签不参与定位。
- 时频核查：在同一标注范围内寻找 2-16 kHz 对数幅度谱的最大正频谱通量。它只做敏感性审计，不参与主切窗。两种中心的中位绝对差为 1.27 ms，80.3% 在 10 ms 内，87.5% 在 25 ms 内。50 ms 结果因此比 100/200 ms 更容易受定位误差影响。
- 事件窗：以时域峰值为中心截取 50、100、200、250、500、1000 ms。
- 严格 Pre：长度与事件窗相同，结束点位于 `event_start` 前 50 ms，因此不会包含击球音头；历史不够长时跳过样本，不向 WAV 补零。
- 事件移除：仅对 1000 ms 窗口保留前后上下文并移除标注事件，用于回答“没有击球本身时，同一规则还能否分类”。

## 4. 分类器如何训练

主分类器是通常意义上的二分类逻辑回归，只是增加 L2 正则化。逻辑回归先计算 embedding 各维的加权和，再通过 sigmoid 转成属于 fly ball 的概率。L2 会惩罚过大的整体权重，降低小样本记忆噪声的风险；`C` 是正则化强度的倒数，越小约束越强。本实验只预设 `C=0.001/0.01/0.1`。

三条预注册分析分支为：无 PCA 的 L2 逻辑回归；训练折内 PCA32 后的 L2 逻辑回归；训练折内 PCA32 后的收缩 LDA。PCA 不是必需步骤，只是检查把高维 embedding 压到 32 个综合方向是否更稳。标准化和 PCA 都只在当前训练折拟合。

### 为什么是外层 5 折、内层 3 折、重复 5 次

外层是最终考试，用于估计未见来源的泛化；内层只在外层训练数据中选择窗口、PCA 分支和 `C`。因此不存在固定的单一“训练/验证/测试比例”：每个外层折大约 80% 开发数据用于训练与内层验证、20% 用于外层测试；内层再把这 80% 切成约 2/3 内层训练和 1/3 内层验证。5 次重复只是更换来源分组的折法并报告波动，不是对同一个网络训练 25 个 epoch。

全局自由选择的 BA 为 **0.573 +/- 0.027**，而且 25 个外层折的选择分散，说明在 320 条样本上同时自由选择所有模型、窗口和分类器不稳定。因此主结论来自固定窗口/固定分类器，窗口族嵌套结果只作次要分析。

## 5. 指标怎样读

- Balanced Accuracy（BA）：分别计算 fly 和 ground 的召回率，再取平均。随机二分类约 0.5；总猜多数类也只有约 0.5，适合当前 102 对 218 的不平衡数据。
- ROC-AUC：不固定某个概率阈值，衡量随机抽一条 fly 时，其预测分数高于随机 ground 的概率。0.5 约为随机，1.0 为完美排序。
- Macro-F1：先分别计算两类 F1，再平均，同时考虑漏判与误报。
- MCC：综合四格混淆矩阵，0 约为无相关，1 为完全正确，-1 为完全相反。小样本和类别不平衡时可作为稳健补充。
- 本项目不能只定一个“达标 BA”。约 0.55-0.60 只能算弱信号，0.60-0.70 可称弱到中等；是否可信还必须看标准差、负控和校正置换。当前没有足够证据设定部署标准。

## 10. 标签置换与多模型校正

确认性检验固定为 `StandardScaler + L2 逻辑回归 C=0.01 + 无 PCA + 一套来源分组 5 折 OOF`，不再选择分类器。标签按来源整组置换 99 次，并在每个窗口范围内用 max-stat 校正全部模型。

这里的 M2D 观察 BA（200 ms 为 0.616）与第 6 节的重复嵌套均值（200 ms 为 0.590 +/- 0.011）不是同一个估计量：前者固定 `C` 和一套 5 折，专门用于置换检验；后者在每个外层训练折内选 `C` 并重复 5 次，专门用于性能汇报。两者回答的问题不同，不能混为同一分数。

## 11. 采集混杂审计

| 特征组 | BA | ROC-AUC |
| --- | --- | --- |
| 仅标注区间形状 | 0.474 +/- 0.017 | 0.481 +/- 0.024 |
| N/A | 0.533 +/- 0.007 | 0.544 +/- 0.007 |
| 仅原文件总时长 | 1.000 +/- 0.000 | 1.000 +/- 0.000 |
| 事件在文件中的相对位置 | 0.721 +/- 0.015 | 0.759 +/- 0.003 |

仅用原文件总时长即可得到 1.000 BA；事件相对位置也约 0.721 BA。primary_dev 的采集者字段本身是常量 `Codex_Workstation`，所以“按采集者分组”无法消除同一工作站内不同裁剪流程造成的偏差。外部数据中采集者与标签完全绑定，Cramer's V 为 1.0，因此外部集不能作为无偏泛化测试。

固定事件窗没有把 `audio_duration` 字段输入分类器，所有分类器只读取 `feat_*` 列；但是总时长完美分离证明两类文件的生成流程不同。当前最合理的解释是：模型同时利用了事件、上下文以及采集流程残留，三者比例尚不能完全识别。

## 12. 当前推荐与下一阶段

1. 以 **M2D 40 ms 冻结 embedding + 无 PCA L2 逻辑回归** 作为首选 baseline；Traditional 181D 作为必须保留的低成本参照。
2. 主要科学窗口使用 **200 ms**；同时报告 100 ms 和 50 ms 定位敏感性，1000 ms 只作为“带上下文预测能力”参照，不作为击球特异性证据。
3. 每次结果必须同时报告事件、严格 Pre、以及可用时的事件移除；不要再使用可能含击球音头的旧式 `Pre100` 定义。
4. 在现有数据上可继续做成对事件增量、来源/裁剪规则分层、频带消融和时频峰值重切窗敏感性，但这些都不能完全替代新数据。
5. 暂不端到端微调大型模型。只有当拥有按采集流程平衡、以来源为单位的独立测试集，且样本至少进入千级后，再考虑小学习率、冻结大部分层、早停的微调。
6. 未来采集必须让每个设备/采集者/裁剪流程同时包含两类，原始长度规则一致，并保留独立来源测试集。否则再多同流程样本只会让模型更确定地学习偏差。
