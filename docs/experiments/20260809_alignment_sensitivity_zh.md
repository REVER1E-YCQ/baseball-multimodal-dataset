# M2D 对齐敏感性诊断（2026-08-09）

**状态：** 已完成；**数据：** 同锁定基准快照

## 问题

窗口以标注区间内幅度峰值为中心，但部署数据不会有精确人工对齐。headline 0.667 有多少依赖"窗口恰好对准瞬态"？

## 方法

给切窗机制加 `event_shift_ms`（窗心 = 峰值 + 偏移），在 {−100, −50, −25, 0, +25, +50, +100} ms 上跑同一冻结 M2D attention 协议，输出偏移→BA 曲线。判读规则：±50 ms 掉 ≤0.02 = 用粗粒度内容；≥0.05 = 依赖精确对齐（部署需自动对齐器）。

## 结果

- 0 ms 参考：0.666
- ±50 ms 平均下降：**0.022 → 判读为"中等对齐依赖"**
- 偏移曲线并非单调（非对称），但总体随偏移增大而下降
- 各偏移下严格 Pre 负控保持随机水平

## 结论

模型主要使用事件窗内的内容而非毫秒级精确对准，±50 ms 内性能损失约 2 个百分点；但时间抖动增强（见增强实验）会伤性能，说明完全放弃居中也不行。部署时保留峰值居中即可，无需额外自动对齐器。
