# M2D LoRA 微调试点（2026-08-09）

**状态：** 已完成，方向关闭（负结果）；**数据：** 同锁定基准快照

## 问题

冻结表示方向全部探索完毕后，最后一个容量假设：微调 M2D 编码器本身能否超过冻结线性探针？风险明确——817 条样本、620 个谱系组，微调极易过拟合来源组。

## 方法

每个外折独立训练 LoRA 适配器（小秩），仅用训练折音频 + 训练折内部分组验证集早停；测试折完全不参与拟合与早停。与同折的冻结 mean 基线对比。

## 结果

| 配置 | Event BA |
|---|---:|
| 冻结 mean（同折基线） | **0.595** |
| LoRA 微调 | 0.556 |
| 差值 | **−0.039** |

过拟合特征明确：各折早停在 13–27 epoch，训练 − 内部验证差 +0.045。

## 结论

在当前数据规模下微调编码器是净损失。**微调方向关闭**；除非数据量数倍增长，否则应继续使用冻结编码器 + 轻量分类头。
